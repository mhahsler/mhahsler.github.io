Many functions in R (e.g., \texttt{print}, \texttt{plot}) look at the
supplied object and then choose automatically an appropriate behavior.
These functions are called \textbf{generic} functions. The
\textbf{implementations} have the object type in the name after a dot.

\vfill

\textbf{Example:} \texttt{print} is generic and calls for a data.frame
the implementation \texttt{print.data.frame}.

\begin{Shaded}
\begin{Highlighting}[]
\KeywordTok{print}\NormalTok{(x)}
\end{Highlighting}
\end{Shaded}

\begin{verbatim}
##   a b
## 1 1 A
## 2 2 B
\end{verbatim}

You can find the manual page using \texttt{?\ print.data.frame}

\vfill

\begin{block}{Hint}
\protect\hypertarget{hint}{}
When you type a function name in RStudio, it shows you all the
implemented methods in the auto-completion context menu.
\end{block}
\end{frame}

\hypertarget{exercises}{%
\section{Exercises}\label{exercises}}

\begin{frame}[fragile]{Exercises}
\protect\hypertarget{exercises-1}{}
\begin{enumerate}
\item
  Create x by \texttt{x\ \textless{}-\ runif(100)}. Write a function
  with the name \texttt{avg\_gt} with two formal arguments: a vector x
  and a value gt. The functions computes the average of the values
  greater than gt in x. Write a version with a loop and if and one
  version without loops and if statements.
\item
  Create a list with 5 numeric vectors (lengths and values of your
  choice). Sort all vectors in the list. Hint: see \texttt{sort()}.
\item
  Write a function that computes the smallest value in each column of a
  given matrix. Create a random \(5\times5\) matrix to test the
