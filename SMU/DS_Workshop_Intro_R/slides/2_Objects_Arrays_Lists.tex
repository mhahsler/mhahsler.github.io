\begin{frame}[fragile]{Regular attributes III}
\protect\hypertarget{regular-attributes-iii}{}
\textbf{Notes:}

\begin{itemize}
\item
  \texttt{mode}, \texttt{storage.mode}, and \texttt{class} are
  confusing!
\item
  \texttt{class()}returns the class of an object (same as
  \texttt{attr(x,\ \textquotesingle{}class\textquotesingle{})}). If the
  object does not have a class attribute (S3) or an implicit class
  (matrix, array, integer) then it returns the storage type
  (\texttt{storage.mode}).
\end{itemize}

\begin{block}{Recommendation}
\protect\hypertarget{recommendation}{}
\begin{itemize}
\tightlist
\item
  Often data types are not read correctly (e.g., numbers might be read

  they are nominal variables). Variable names have extra dots at the
  end. These need to be fixed (see next slide).
\item
  There may be issues with different versions of Excel. It is often
  easier to export the spread sheet from Excel as a CSV file to be read
  by R.
\end{itemize}
\end{block}
