The R package rBLAST interfaces the Basic Local Alignment Search Tool (BLAST) to search genetic sequence data bases so it can be used in Bioconductor workflows.

![Bioc rBlast landing page]({{ '/assets/img/rBLAST_on_Bioc_2024.webp' | relative_url }}){: loading="lazy" decoding="async" }



Details about the package can be found on
[rBLAST's Bioconductor page](https://bioconductor.org/packages/rBLAST).
