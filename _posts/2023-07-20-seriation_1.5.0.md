![seriation logo](https://github.com/mhahsler/seriation/raw/master/man/figures/logo.svg)

The new major release v1.5.0 of the R package seriation contains many changes:

* New seriation methods include: AOE, isomap, monoMDS, metaMDS (from vegan), enumerate, mean, SGD, LLE.
* Improved handling of heatmaps.
* Support for reordering correlation matrices and better integration with other packages 
including corrplot, corrr and corrgram.
* Seriation methods are now registered with the seriation criterion they try to optimize. This information
  is used in the new option to restart randomized methods and report the best found solution.
* The README now includes howtos for reordering heatmaps, reordering correlation matrics, and evaluating clusters.

Details of the changes can be found in the package's [NEWS file](https://github.com/mhahsler/seriation/blob/master/NEWS.md). The new version is available from [CRAN](https://CRAN.R-project.org/package=seriation) or [GitHub](https://github.com/mhahsler/seriation).
